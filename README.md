# LlamaIndex RAG Learning Project

A beginner-friendly project for learning **Retrieval-Augmented Generation (RAG)** using **LlamaIndex, TypeScript, and Groq**.

## Tech Stack

- TypeScript
- Node.js
- LlamaIndex
- Groq
- Llama 3.3
- Vercel AI SDK

## Project Goal

The goal of this project is to understand how RAG works by building a simple application that can answer questions using information from local documents or database step by step.
